Experiment 03: Batch Normalization

Hypothesis:
- Test whether applying Batch Normalization before the ReLU activations accelerates 
  training and stabilizes the learning process by reducing internal covariate shift.

Kept equal to baseline:
- Original, unnormalized image inputs.
- SGD with learning rate 3e-4, momentum=0.9 and nesterov=True.
- Batch size: 16.
- Maximum epochs: 100.
- Same train/validation split and callbacks.

Changed:
- Architecture changed to include Batch Normalization (BN):
  Flatten -> Dense(512) -> BN -> ReLU -> Dense(256) -> BN -> ReLU -> 
  Dense(128) -> BN -> ReLU -> Dense(64) -> BN -> ReLU -> Dense(13).
- Checkpoint and prediction paths point to experiment_03.

Challenge compliance:
- Feedforward neural network using dense layers only.
- No CNN, transfer learning, or classical data augmentation.
- USES batch normalization, which is the focus of this experiment.

Results:
- Best validation model: epoch 28.
- Training stopped at epoch 58 due to the early-stopping criterion.
- Mean Accuracy: 63.810%.
- Mean Recall: 59.870%.
- Mean Precision: 65.340%.

Conclusions:
- Batch Normalization dramatically accelerated convergence, finding the best validation 
  model at epoch 28, much earlier than standard networks or those with L2/Dropout.
- It yielded a strong boost in accuracy (~63.8%) and precision, making the gradients 
  much more stable despite the deep dense architecture.
- However, some overfitting reappeared in later epochs, suggesting BN alone might 
  benefit from being paired with another regularizer.
